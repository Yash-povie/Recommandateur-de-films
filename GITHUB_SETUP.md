# GitHub Setup Guide

## Files to Add to GitHub

### ✅ Required Files (Add These)

```
Movie Recommendation system/
├── .gitignore                    # Git ignore file (excludes large files)
├── README.md                      # Main project documentation
├── ARCHITECTURE.md                # Architecture and usage guide
├── requirements.txt               # Python dependencies
│
├── app.py                         # Main Streamlit application
├── train_models.py                # Training script
├── example_usage.py              # Example usage (if exists)

│
└── src/                           # Source code directory
    ├── __init__.py
    ├── data_loader.py            # Data loading and preprocessing
    ├── content_based.py          # Content-based filtering
    ├── collaborative.py          # Collaborative filtering
    ├── hybrid.py                 # Hybrid recommendation engine
    └── gpu_utils.py              # GPU utilities
```

### ❌ Files to EXCLUDE (Don't Add These)

These files are too large for GitHub and will be generated by users:

```
├── models/                        # Pre-trained models (too large)
│   ├── *.pkl files
│
├── data/                         # Dataset files (too large)
│   └── ml-25m/
│       ├── movies.csv
│       ├── ratings.csv
│       └── ...
│
├── __pycache__/                  # Python cache
├── *.pyc                         # Compiled Python files
├── venv/                         # Virtual environment
└── .env                          # Environment variables
```

## GitHub Setup Steps

### 1. Initialize Git Repository

```bash
# Navigate to project directory
cd "D:\Movie Recomendation system"

# Initialize git repository
git init

# Add .gitignore file
git add .gitignore

# Add all required files
git add README.md ARCHITECTURE.md requirements.txt
git add app.py train_models.py
git add src/
git add .gitignore

# Commit files
git commit -m "Initial commit: Movie Recommendation System"
```

### 2. Create GitHub Repository

1. Go to https://github.com
2. Click "New repository"
3. Name it: `movie-recommendation-system` (or your preferred name)
4. **Don't** initialize with README (you already have one)
5. Click "Create repository"

### 3. Push to GitHub

```bash
# Add remote repository (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/movie-recommendation-system.git

# Push to GitHub
git branch -M main
git push -u origin main
```

## For Users Cloning Your Repository

### Step 1: Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/movie-recommendation-system.git
cd movie-recommendation-system
```

### Step 2: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 3: Download Dataset

1. Download MovieLens 25M dataset from: https://grouplens.org/datasets/movielens/
2. Extract and place in `data/ml-25m/` directory:
   ```
   data/
   └── ml-25m/
       ├── movies.csv
       ├── ratings.csv
       └── ...
   ```

### Step 4: Train Models

```bash
python train_models.py
```

This will create the `models/` directory with trained models.

### Step 5: Run Application

```bash
streamlit run app.py
```

## Repository Size

- **Code files**: ~50-100 KB (small, perfect for GitHub)
- **Models**: ~500MB - 2GB (excluded via .gitignore)
- **Dataset**: ~250MB - 1GB (excluded via .gitignore)

**Total GitHub repository size**: ~100 KB ✅

## Optional: Add Pre-trained Models

If you want to share pre-trained models (optional):

1. **Option 1**: Use Git LFS (Large File Storage)
   ```bash
   git lfs install
   git lfs track "*.pkl"
   git add .gitattributes
   git add models/*.pkl
   ```

2. **Option 2**: Upload to cloud storage (Google Drive, Dropbox, etc.)
   - Share download link in README
   - Users can download and place in `models/` directory

3. **Option 3**: Don't include models (recommended)
   - Users train their own models
   - Keeps repository small
   - Models are generated from dataset anyway

## Summary

✅ **Add to GitHub:**
- All Python source code files
- Documentation files (README, ARCHITECTURE)
- Configuration files (requirements.txt, .gitignore)
- Training and application scripts

❌ **Don't Add:**
- Pre-trained models (.pkl files)
- Dataset files (.csv files)
- Python cache files (__pycache__)
- Virtual environments (venv/)

This keeps your repository small and fast while allowing anyone to clone and use your system!
